Homepage Welcome Card Slideshow

Place dedicated school photos in this folder (JPG, JPEG, PNG, WEBP, or AVIF).
Then list each filename, in display order, in slides.json. Example:

{
  "intervalMs": 7000,
  "images": ["campus-01.jpg", "classroom-02.webp", "sports-day.png"]
}

The welcome card uses only files listed here and advances through them in order.
The interval is milliseconds and is limited to 3–60 seconds by the page.
